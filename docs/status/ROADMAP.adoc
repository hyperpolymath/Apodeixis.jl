= Apodeixis.jl Roadmap
:toc:

Apodeixis is at the source-policy audit stage. Its implemented Julia API and
CLI parse source with JuliaSyntax without executing the input. Policy-clean
output is not a proof of functional correctness, bounds safety, allocation
behaviour, or ABI correctness.

== Current maintenance

* Keep the package tests aligned with the documented fail-closed subset,
  including rejection of global declarations at every source scope.
* Replace inherited template setup documents with instructions for the actual
  Julia package.
* Instantiate the inherited deed and generated arrival pack through the estate
  identity/registry process. They still describe the template and cannot support
  a production-readiness claim for Apodeixis.

== Planned implementation

The authoritative work sequence is
link:../architecture/APODEIXIS-MVP-IMPLEMENTATION-PLAN.adoc[the MVP implementation
plan], with the detailed dependency graph in
