= Proof Status — {{PROJECT}}

This is the repository's proof-status file in the sense of
`standards/3-practice/PROOF-POLICY.adoc` §8.5: one row per claim, with its status
token, its Proof Witness Grade (PWG) and its recheck legs. The estate census
(hyperpolymath/mathesis) reads this file. A row says only what a receipt or a
gate supports.

A freshly minted repository has no claims, so the table is empty. That is the
honest state. Do not replace it with a percentage or an "overall" figure:
§8.4 forbids percentages, averages and single scores for proofs.

== Vocabulary

* *Status token* (§5): `proven`, `proven-with-postulates`, `tested-only`,
  `argued`, `open`.
* *PWG* (§8), always written with its prefix, never as a bare "Grade":
** `PWG-3`: the Agda proof is `proven` under the canonical §2.1 invocation,
   `agda --safe --without-K --cubical-compatible`;
** `PWG-2i`: one recheck leg also counts (Rocq or Lean);
** `PWG-2ii`: both legs count;
** `PWG-1`: every counted witness has a current receipt for the exact commit;
** `ungraded`: a theory theorem below `PWG-3`;
** `n/a`: not a theory theorem (a test, a refusal fixture, an assumption, or an
   engineering proof in Idris2, SPARK, Creusot or Verus). §8.1 puts these off the
   ladder.
* *Recheck legs* (§2): `transported`, `re-proved`, `waived` or `unavailable`,
  each with its §2.2 correspondence state, for example `BRIDGE-PENDING` or
  `RECONCILED`. A leg counts towards a grade only when it is `RECONCILED`.

A grade is derived from receipts, not asserted (§8.4). Name the receipt in the
table, and a claim that has none stays `ungraded`. `PWG-3` is not a discharge:
a theorem at `PWG-3` still owes both legs.

The template's own sample proofs under `verification/proofs/` are boilerplate.
They are never rows here: replace them with this repository's proofs, or delete
them.

== Verification commands

[source,bash]
----
just proof-check-agda     # Agda: agda --safe --without-K --cubical-compatible
just proof-check-coq      # Rocq recheck legs
just proof-check-lean4    # Lean recheck legs (core only, no Mathlib)
just proof-check-idris2   # Idris2 engineering proofs
just proof-check-all      # every prover; fatal if a toolchain is absent
----
