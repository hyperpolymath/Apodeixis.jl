= Setting up Apodeixis.jl
:toc:

Apodeixis is a Julia source-policy auditor. Its current `POLICY CLEAN` result
is not a verification proof. The Idris2/Zig interface tree is scaffolding,
not a prerequisite for running the Julia package.

== Install and test

Clone `hyperpolymath/Apodeixis.jl`, enter the checkout, and use Julia 1.9 or
a later 1.x release, as declared in `Project.toml`:

[source,bash]
----
julia --project=. -e 'using Pkg; Pkg.instantiate(); Pkg.test()'
julia --project=. scripts/apodeixis.jl --help
julia --project=. scripts/apodeixis.jl audit path/to/source.jl
----

The CLI returns 0 for policy-clean source, 1 for rejected source, and 2 for
usage or input errors. A manually supplied `--mutation-score 95` is a policy
input, not authenticated evidence or a bounds proof.

== Development

Change the Julia implementation in `src/Apodeixis.jl`, and run the package
tests in `test/runtests.jl`. Do not evaluate the source being audited.
The initial policy rejects global declarations at file scope and in functions;
an `@verified` marker does not exempt otherwise forbidden constructs.

See link:architecture/APODEIXIS-MVP-IMPLEMENTATION-PLAN.adoc[the implementation
plan] for the implemented subset and the planned proof pipeline.
