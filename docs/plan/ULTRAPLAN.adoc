= Apodeixis.jl: plan to v1.0.0
:revdate: 2026-11-15
:toc:

Apodeixis.jl is a Julia source-policy audit today. The goal is a verifier for
a closed Julia subset. This plan is the execution layer. The work packages
WP-00 to WP-11 and the milestones M0 to M8 stay in
link:../architecture/APODEIXIS-ULTRAPLAN.adoc[the detailed plan]. The slices A
to J stay in link:../architecture/APODEIXIS-MVP-IMPLEMENTATION-PLAN.adoc[the
MVP plan]. This file adds the v1.0.0 gates, the order, the models and the
effort.

The work that is shared with the sibling verifiers (`atoma`, `quintessence`,
`bactrian`, `canonry`, `chancel`) is in the family plan,
`docs/plan/FAMILY-ULTRAPLAN.adoc` in `hyperpolymath/atoma`. IDs F1 to F12 and
waves W0 to W5 come from that plan.

== Definition of v1.0.0

The seven family gates apply. The text below is the Apodeixis reading.

[cols="1,4,3",options="header"]
|===
| Gate | Acceptance | Falsifier
| Language boundary | Closed subset on typed SSA from `code_typed`, with an allow-list. Dynamic dispatch, `eval` and unmodeled foreign calls fail closed. | A method added after verification changes behaviour and the evidence stays valid.
| Source connection | Obligations come from the specialised method body. The key binds the method instance, the Julia version and the world age. | A body, a dependency or a Julia version changes and old evidence is reused.
| Semantics | Numeric tiers 1 to 4 with no silent crossing. Arrays and loops with invariants. FFI through a checked ABI manifest. | An `Int` overflow or an out-of-bounds read is accepted.
| Replay | A source-derived obligation replays through ECHIDNA. Status PROVED never comes from a solver exit code alone. | UNKNOWN or a timeout becomes PROVED.
| Practical coverage | Three pilots: scalar kernel, array loop, one FFI wrapper. | A second package needs special cases.
| Assurance | Mutation evidence replaces the supplied score. Package tests and the gate run on both supported Julia versions. | A mutant survives because a check did not run.
| Release and estate | Registered in the General registry or documented as not registered. README, deed and changelog true. | A `POLICY CLEAN` result is described as a proof.
|===

=== First external target: CoprocessorRuntime.jl

Source-policy audit, not a proof. Measured with the Julia 1.12.1 build of this
auditor on `hyperpolymath/CoprocessorRuntime.jl` at commit `a0e2c82`
(`a0e2c823cbc87905b9810641fd8bb55e4b7eeef6`). The clone was read only and no
code from it ran.

* Before: `audit` on each of its 8 source files. 7 files were policy clean. The
  package root `src/CoprocessorRuntime.jl` had 7 findings, all
  `APX_DYNAMIC_ESCAPE: include is forbidden in the closed verified subset`.
  No real package could pass, because a package must `include` its own files.
* After: `audit-package src/CoprocessorRuntime.jl` reaches 8 files, all policy
  clean, with 0 package findings and 0 unreached files. Exit code 0.
* What changed: `audit_package` permits one form of `include` (one plain string
  literal, as a statement at top level or directly in a module body, path
  relative, ending in `.jl`, inside the root directory) and audits the included
  file. `audit_file` and `audit_source` still forbid `include`.
* What this does not show: the package is not verified. The audit is a
  deny-list over syntax.

The mapping from slices to milestones is approximate. The detailed plan is the

Sonnet does the implementation tasks inside each stage from an Opus brief.
Haiku runs the scout pass before each step. The advisor reviews the close of
each stage and each change to a status word.

== What Apodeixis.jl takes from the family, and gives

* Takes: the evidence kit (F3), the ECHIDNA client (F7), Zig checks from
  `atoma` (F8).
* Gives: the numeric tier model. It is the natural owner of the Julia side of
  an ECHIDNA coprocessor contract (F10), if the owner opens that work.
* The coprocessor is not wired today. No file in this repository refers to it.

== Stop points

* If the compiler adapter (M2) cannot give stable typed SSA across the two
  supported Julia versions, narrow the supported versions. Do not weaken the
  source connection gate.
* Do not start A3 before it is split into parts of size L or smaller.
