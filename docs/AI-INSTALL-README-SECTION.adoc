= Apodeixis installation entry points

`README.adoc` describes the existing Julia package and its source-policy limits.
Use link:SETUP.adoc[manual setup] or
link:AI_INSTALLATION_GUIDE.adoc[the AI development guide] to install and test it.

The template's repository-minting README snippet does not apply to Apodeixis.
Installing this package does not create another repository, run `repo-init`,
or establish a new estate identity. The inherited deed and arrival pack still
need the separate identity/registry instantiation recorded in the roadmap.
