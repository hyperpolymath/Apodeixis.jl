== Implementation for an AI agent

This is an existing Julia package, not a template to instantiate. Start with
`README.adoc`, `Project.toml`, `src/Apodeixis.jl`, and `test/runtests.jl`.
Use link:SETUP.adoc[the package setup instructions].

Run `julia --project=. -e 'using Pkg; Pkg.instantiate(); Pkg.test()'` before
and after a code change. Preserve the fail-closed policy and the distinction
between a source-policy audit and a proof. Never execute input source, expand
its macros, or turn a manually supplied mutation score into a verification
claim. Check expectations against the implementation plan before changing a
security rule to satisfy a test.

The repository contains inherited template documents and an uninstantiated
deed/arrival pack. Their template identity and production status do not describe
Apodeixis. Do not create another repository, mint an identity, or run `repo-init`
as part of installing or testing this package.

== Privacy

Package installation contacts Julia registries and package servers to download
dependencies. The source-policy auditor reads local source and emits local
diagnostics; it does not need a network service to audit a file. External AI
assistants have their own data handling policies: do not send private source or
credentials to one without the owner's consent.
